Longer description, if the portal has a second field:

> Number Stack is a quick, satisfying number puzzle. Drag a tile onto an identical neighbour to merge them into double the value, or slide it into an empty cell to make room. Each move adds a new tile, so the board fills up fast: plan ahead, chain merges for big scores, and see how high you can stack. ## Accessibility tags (AGI)
Tag only what is true. Facts about this game, checked in the code:
- Text and tile contrast is at least 4.5:1 in all four themes.
- Turn-based: no timers, no time pressure, no flashing effects.
- Plays with a single pointer (touch or mouse); no multi-touch, no precision gestures.
- The game never requires sound; audio is only feedback. It follows YouTube's mute.
- Respects the system "reduce motion" setting.
- Not supported (do NOT tag): keyboard-only play, screen reader support, colour-blind mode, text size options.

## Bundle for upload
Build with `npm run build`, then zip the CONTENTS of `dist/` (so `index.html` is at the zip root).
File names use only letters, numbers, `-`, `_` and `.`; all paths are relative.
